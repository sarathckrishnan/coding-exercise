This repo contains the solutioning for the progamming exercise.

The assumptions made for the solution.
1) The file ukpostcodes.csv is locally available for processing. It's kept as part of the repo at src/java/resources.

The solution has logic spread across three files. 
1) PropertyLoader - Reads configuration.properties files which makes the inputfile, outputfile and character used to plot the ascii art configurable.
2) ReadInputCSV - Reads the CSV file. 
3) ASCIIMapGenerator - It drives the execution, calling ReadInputCSV to fetch the coordinates for postcodes, plots the ascii art and saves it to a text file.

Notes :
1) Open CSV is used for csv processing. 

How to run the solution?
1) Once cloned, do a mvn clean install for the dependencies 
2) Run ASCIIMapGenerator.java for the output
